# Hotel Management Data Analysis

## Project Overview
This project focuses on analyzing hotel booking data to understand booking trends, cancellations, revenue performance, and guest behavior. The analysis helps identify important business insights that can support better hotel management and decision-making.

## Tools & Technologies
- **Python:** Data cleaning, preprocessing, and Exploratory Data Analysis (EDA) using Pandas, NumPy, and Matplotlib.
- **SQL (MySQL):** Data analysis using SQL queries to identify business trends and insights.
- **Power BI:** Interactive dashboards and visualizations to monitor hotel performance.

## Dataset
The project uses a hotel booking dataset containing information about bookings, customers, room details, revenue, and cancellations.

The dataset used in this project is cleaned and prepared for analysis.

## Project Workflow

### 1. Python – Data Cleaning & EDA
- Inspected the dataset and its structure.
- Handled missing values and duplicate records.
- Performed data preprocessing.
- Explored booking patterns and trends.

### 2. SQL – Business Analysis
- Analyzed hotel booking data using SQL.
- Examined booking and cancellation patterns.
- Analyzed revenue performance.
- Identified insights related to guest types and hotel operations.

### 3. Power BI – Dashboard Development
Created interactive dashboards to analyze:
- Total Bookings
- Cancellation Rate
- Average Daily Rate (ADR)
- Revenue Performance
- Booking Trends
- Guest Type Analysis
- Hotel Performance

## Key Business Insights
- Evaluated hotel booking and cancellation patterns.
- Analyzed revenue performance across different categories.
- Compared guest types and booking behavior.
- Identified trends to support hotel business decisions.
