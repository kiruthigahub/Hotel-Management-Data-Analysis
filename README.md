# Hotel Management Data Analysis

## Project Overview

This project focuses on analyzing hotel booking data to understand booking trends, cancellation patterns, revenue performance, and guest behavior.

The objective is to transform hotel booking data into meaningful business insights using Python, SQL, and Power BI to support data-driven decision-making and improve hotel operations.

## Tools & Technologies

- **Python:** Data analysis and exploratory data analysis (EDA) using Pandas, NumPy, and Matplotlib.
- **MySQL:** Data querying and business analysis using SQL.
- **Power BI:** Interactive dashboards and data visualization.
- **Excel:** Dataset storage and data handling.

## Dataset

The project uses a hotel booking dataset containing information related to hotel reservations, customer details, booking status, revenue, and other booking attributes.

The dataset included in this repository is the cleaned dataset used for the analysis.

**Dataset File:** `Hotel_Booking_Analytics_Dataset.xlsx`

## Project Workflow

### 1. Python – Data Analysis

- Explored the hotel booking dataset.
- Examined dataset structure and data types.
- Performed exploratory data analysis.
- Analyzed booking patterns and trends.
- Identified important factors affecting hotel bookings and cancellations.

### 2. SQL – Business Analysis

Used MySQL to perform business-oriented analysis, including:

- Analyzing total hotel bookings.
- Examining booking cancellation patterns.
- Analyzing revenue performance.
- Comparing booking trends across guest categories.
- Identifying useful business insights through SQL queries.

### 3. Power BI – Dashboard Development

Developed interactive dashboards to visualize hotel performance and booking patterns.

**Key Performance Indicators (KPIs):**
- Total Bookings
- Cancellation Rate
- Average Daily Rate (ADR)
- Revenue

**Dashboard Analysis:**
- Booking Trends
- Revenue by Guest Type
- Booking Analysis by Guest Type
- Hotel Booking and Cancellation Performance

Interactive slicers are included to explore the data from different perspectives.

## Key Business Objectives

- Understand hotel booking trends.
- Monitor booking cancellation rates.
- Evaluate revenue performance.
- Analyze guest booking behavior.
- Identify patterns that can support better business decisions.
